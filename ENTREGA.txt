TP1 - Aplicaciones Móviles y Cloud Computing

Tema: DJ Meet, salas colaborativas para proponer y votar canciones de YouTube.
Integrantes (apellido y nombre):
- Fernandez Mauro Nicolas
- Franco Cobatti

URL pública del frontend: https://dj-meet-production.up.railway.app/
URL pública de la API: https://dj-meet-production.up.railway.app/api/propuestas.php
Para consultar propuestas, agregar ?salaId=ID con el identificador de la sala y una sesión activa.

Para probar: crear una sala en el inicio y luego abrirla desde otro navegador con el código.
La API usa la sesión de ese navegador. Se puede obtener el id de sala en la respuesta de api/salas.php?codigo=CODIGO.

Repositorio: https://github.com/Mauronfernandez9/dj-meet


Proveedor cloud: Railway (PaaS). Servicio PHP/Apache en Docker y servicio MySQL separado.
Servicios externos: YouTube desde el navegador; iTunes Search API desde PHP.
